# site

Deux démos GSAP (https://gsap.com) dans ce repo :

- **App React/Vite** (racine) — utilise `gsap` + `ScrollTrigger` dans un composant React.
  ```
  npm install
  npm run dev
  ```
- **`static-demo/`** — page HTML/CSS/JS sans build, GSAP chargé via CDN. Ouvrir `static-demo/index.html` dans un navigateur.
